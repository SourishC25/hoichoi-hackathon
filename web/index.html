How Birati decides where, whether and what

    
    
      
  1. Perception (frame-precise). Camera cuts (ffmpeg scdet), speech activity (Silero VAD —
        language-agnostic, so Bengali/English code-switching doesn't matter), loudness, fades to black, plus
        CLIP embeddings of every second of video and CLAP embeddings of every 5 s of audio.
        All free, open-weights models running on CPU — no API keys.
    2. 
      
  2. Scenes. A new scene starts when a shot looks unlike everything in the previous minute (CLIP), so
        shot/reverse-shot dialogue stays one scene. Each scene is tagged zero-shot with activities and sensitive
        topics — vocabulary taken at runtime from the brand catalogue — using visual (CLIP) and acoustic (CLAP:
        crying, screaming, sirens…) evidence.
    3. 
      
  3. WHERE. Each scene boundary / fade is snapped to a frame-exact camera cut inside a speech-free gap.
        No clean cut nearby → rejected: mid-sentence cuts are structurally impossible. Cut quality combines visual
        change, silence, speech density, loudness dip, fades and music carry-over.
    4. 
      
  4. WHAT. Every brand phrase is scored against the lead-in scene (dominant activity wins). Negative
        contexts are a hard, fail-closed block from three independent layers: scene tags, a lead-in window check,
        and a dense 2 fps verifier on the final pick with stricter thresholds.
    5. 
      
  5. WHETHER. An exact dynamic programme picks the best set of breaks under max breaks/hour, min gap and
        the ad-load budget. Weak moments get no break at all.
    6. 
      
  6. Calibrated. Thresholds were tuned against multimodal-LLM (Gemini) labels from development runs —
        teacher → student — with leave-one-episode-out validation.
    7. 
      
  7. Output. IAB VMAP 1.0 with inline VAST 3.0, a debug JSON explaining every decision, and this player,
        which reads the VMAP, cuts on the exact frame, plays the ad and resumes.
    8. 
    

    

  




  

    
Process your own episode (free, offline, no API keys)

    
This public demo is a free static site, so it plays precomputed runs of the sample episodes.
      The full pipeline runs on any laptop CPU with free open-source models (CLIP, CLAP, Silero VAD) — a 25-minute
      episode takes a few minutes, with live progress, upload, Google-Drive-link ingest and catalogue re-runs:

    
git clone <this repo> && cd birati
python -m venv .venv && .venv/Scripts/pip install torch --index-url https://download.pytorch.org/whl/cpu
.venv/Scripts/pip install -r requirements.txt
.venv/Scripts/python -m uvicorn app.main:app --port 7860   # then open http://localhost:7860

    
Or headless: python -m app.pipeline.run episode.mp4 --brands my_catalogue.json → VMAP + debug JSON.
